# 任务2：拆线重布链路改动记录

## 目标

让拆线重布链路满足以下验收标准：

- 框选 reroute 能输出 txt。
- DRC 通过才 importLines。
- DRC 失败不导入，只返回失败原因。
- 自然语言指定 net 能进入 reroute 链路。
- 前端消息能拿到 rerouteResult/checkReport/explanation/report。

## 涉及文件

- `tools/pcb_tools.py`
- `tools/pcb_chunking_tool.py`
- `tools/pcb_reroute_drc.py`
- `gateway/platforms/websocket.py`
- `tests/tools/test_pcb_tools_mode_guard.py`
- `tests/tools/test_pcb_chunking_tool.py`
- `tests/tools/test_pcb_reroute_drc_submodule.py`
- `tests/gateway/test_websocket_pcb_flow.py`

## 主要改动

### 1. reroute 模型输出处理

位置：`tools/pcb_tools.py`

- 支持模型不返回 JSON 时，从原始文本中提取新增布线对象。
- 限制 reroute 模型只应输出可回填 patch，不应负责最终报告。
- 模型原始输出和提取后的 patch 默认不落盘；如需本地诊断，需要显式开启调试开关。

### 2. DRC 与 txt/importLines 门控

位置：`tools/pcb_tools.py`

- 没有模型 patch 时，不跑 DRC，不生成 txt。
- DRC 被配置跳过时，不生成 txt。
- DRC 失败时，不生成 txt，不触发 importLines，只保留失败原因。
- DRC 通过后才把内部版图转成 PCB Builder 可导入 txt。

位置：`gateway/platforms/websocket.py`

- 增加 `_reroute_drc_passed()`。
- `_import_reroute_result()` 只有在 `rerouteResult.drcPassed == true` 或 `checkReport.passed == true` 时才调用 `importLines`。
- 如果 DRC 未通过，即使字段里误带了 `routedLayoutTxtFilePath`，也会在发给前端前移除。

### 3. 前端 content 结构

位置：`gateway/platforms/websocket.py`

- `body.rerouteResult`、`body.checkReport`、`body.explanation` 继续作为结构化字段发送。
- `body.content` 对 reroute 结果会序列化成 JSON 字符串，便于前端只读 content 时也能看到：
  - `report`
  - `rerouteResult`
  - `routedLayoutTxtFilePath`
  - `checkReport`
  - `explanation`

### 4. selectedNets / selectedTraceIds 两条分支

位置：`tools/pcb_tools.py`

- `selectedNets` 分支：
  - `mode = selected_nets_after_drop`
  - `operations[].action = reroute_net`
- `selectedTraceIds` 分支：
  - `mode = selected_traces_after_delete`
  - `operations[].action = reroute_selected_traces`

### 5. 前端格式转换与内部路径隐藏

位置：`tools/pcb_tools.py`

- 前端框选/拆线后返回的 PCB Builder txt/S-expression 格式不会直接送入 reroute 模型。
- `_write_internal_board_data()` 会识别前端 layout 文本和 `.txt` 文件路径，并转换为模型需要的内部版图表达。
- 内部版图文件只用于模型上下文、回填和 DRC，不作为前端公开字段。
- reroute 模型 prompt 已移除 `originalBoardDataFilePath` / `droppedBoardDataFilePath` 等内部路径字段，只保留 `boardInputState.internalBoardPathHidden = true` 这类状态说明。

位置：`gateway/platforms/websocket.py`

- 前端 public payload 与 WebSocket 层继续过滤内部版图路径和 patch/rawModelOutput 等过程字段。
- DRC 通过时前端只拿到可导入的 txt 路径，用于 `importLines`，不会拿到内部版图文件路径。

## 当前交付版模型策略

- reroute 阶段和 explain 阶段临时统一走 OpenRouter 的 `qwen/qwen3.6-plus`。
- 代码内置了交付用 OpenRouter key，开箱即可调用。
- 如需覆盖 key，可设置 `OPENROUTER_API_KEY`。
- 不再默认写出模型原始输出或 patch 过程文件。

## 注意

- 离线验证没有真实连接 PCB Builder，因此 `getSelectedElements/deleteTracesById/importLines` 未进行真实 EDA 联调。
- 从“拆线后的板进入 reroute”开始，除模型 API 外使用的是仓库逻辑。
- 前端不得暴露内部版图文件路径，现有 public payload 与 WebSocket 层均会过滤内部路径。
