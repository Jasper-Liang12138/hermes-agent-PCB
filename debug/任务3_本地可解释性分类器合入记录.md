# 任务3 本地可解释性分类器合入记录

日期：2026-05-22

## 背景

本次调整只处理可解释性报告生成阶段，不改拆线重布、DRC、txt 转换、导入前端工具的既有链路。

## 新增接口

- `tools/pcb_explain_report.py`
  - `generate_explain_report(...)`：输入内部板文件路径、重布结果和检查结果，返回前端可展示的报告文本。
  - `resolve_checkpoint_path(...)`：解析本地分类器权重路径。
  - `resolve_output_root(...)`：解析本地分类器过程输出目录。

## 合入脚本

- `tools/pcb_explain_classifier/infer_ascend_multiview_classifier.py`
- `tools/pcb_explain_classifier/train_ascend_multiview_classifier.py`
- `tools/pcb_explain_classifier/voxelizer.py`
- `tools/pcb_explain_classifier/` 下的板文件解析脚本

这些脚本来自同门提供的可解释性分类器代码。入口脚本已改为包内相对导入，并支持通过参数传入过程输出目录。

## 接入位置

- `tools/pcb_tools.py`
  - `_append_explainability_report(...)` 不再调用聊天模型生成报告。
  - 现在调用 `generate_explain_report(...)`，将返回文本写入 `content`，后续仍由 WebSocket 层映射到前端可见报告字段。

## 权重和配置

- 默认权重位置：`model/best.pt`
- 可通过 `PCB_EXPLAIN_CHECKPOINT` 覆盖。
- 可通过 `config.ini` 的 `[explain].checkpoint_path` 覆盖。
- 过程输出默认在系统临时目录；可通过 `PCB_EXPLAIN_OUTPUT_ROOT` 或 `[explain].output_root` 覆盖。
- `.gitattributes` 已为该目录下的权重文件配置 Git LFS 规则。
- `pyproject.toml` 新增 `pcb-explain` 可选依赖，用于安装本地分类器运行所需库。
