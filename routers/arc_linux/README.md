## Basic Flow

```bash
./a.out 1231_4_arc.txt component_input.txt
./b.out layer_input.txt 1231_4_arc.txt
./c.out order_input.txt 1231_4_arc.txt constrain.txt
python3 Turn_QYF.py 1231_4_arc.txt ARC_output.txt 1234_1_arc_output.txt
```

Expected main outputs:

- `layer_input.txt`
  Layer assignment produced by `a.out`.
- `order_input.txt`
  Routing order produced by `b.out`.
- `ARC_output.txt`
  Routed arc/line geometry produced by `c.out`.
- `1234_1_arc_output.txt`
  Final design generated by `Turn_QYF.py`.

## Search Wrappers

The reinforcement-learning version is stored in:

- `rl/run_dqn_arc.sh`
- `rl/train_dqn_arc.py`

Example:

```bash
cd rl
./run_dqn_arc.sh 500
```

Here `500` is the `eval_budget`, which means at most 500 real candidate evaluations.

The genetic/memetic search version is stored separately in:

- `ga/run_ga_arc.sh`
- `ga/train_ga_arc.py`

Example:

```bash
cd ga
./run_ga_arc.sh 200
```

Here `200` is the `eval_budget`, which means at most 200 real candidate evaluations.
See `ga/README.md` for GA details.
